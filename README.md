# fNIRS Glossary Project

The fNIRS Glossary Project is a community-sourced glossary  (i.e., useful nomenclature and related symbols) of terms related to fNIRS technology. The glossary includes terms related to continuous-wave (CW), frequency domain (FD), and time domain (TD) NIRS systems, covering the experimental design, pre-processing, data analysis, neuroscience, physics and mathematical areas that are crucial to understanding and using fNIRS successfully and reliably in research, industry and clinical settings.

This is a private repository to store the database of the project.
